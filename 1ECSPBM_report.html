1ECSPBM Weekly Ticket Report — Delay Tracker

This report tracks Release To Customer Date (RTCD) changes for tickets in the 1ECSPBM Jira project across calendar weeks. Each week, the planned customer release date of every active ticket is recorded. When that date is pushed to a later week compared to the previously recorded value, the change is flagged as a delay. The color-coded timeline makes RTCD slippage instantly visible across weeks and organizational units.

Use the filters below to narrow the view, then press Show Results.
